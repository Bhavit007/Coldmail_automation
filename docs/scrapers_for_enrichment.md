# Scraper libraries saved for later (enrichment plug-in)

Shortlisted for when we optimize the enrichment plug-in. Each needs the team lead's OK before use.
Check current star counts and licenses at that time.

- Crawl4AI: https://github.com/unclecode/crawl4ai (crawler that turns pages into clean text for AI)
- Firecrawl: https://github.com/firecrawl/firecrawl (scrape/crawl API, self-hostable)
- Scrapling: https://github.com/D4Vinci/Scrapling (scraping framework, single request to full crawl)
- Camoufox: https://github.com/daijro/camoufox (anti-detect Firefox)
- CloakBrowser: https://github.com/CloakHQ/CloakBrowser (stealth Chromium, Playwright drop-in)
- browser-use: https://github.com/browser-use/browser-use (AI browser agent)
- camofox-browser: https://github.com/jo-inc/camofox-browser (stealth headless browser)
- Scrapy: https://github.com/scrapy/scrapy (classic Python crawling framework)
